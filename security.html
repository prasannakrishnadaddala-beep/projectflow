Security Overview

VEWIT is built with security-first controls for authentication, workspace isolation, secure transport, operational visibility, and role-aware access across projects, tasks, tickets, messages, and AI features.

Authentication & Access

  • Session-based authentication for user access.
  • Role-aware permissions across Admin, Manager, Team Lead, Developer, Tester, and Viewer roles.
  • Support for two-factor authentication workflows and admin resets where enabled.
  • Workspace-scoped invitation and membership controls.

Data Isolation

  • Workspace-aware application queries designed to keep one workspace separate from another.
  • Scoped task, ticket, project, message, and user access paths.
  • Administrative operations segmented from normal workspace activity.

Transport & Session Protection

  • Security headers applied at the application layer.
  • Cookie protections for session handling.
  • HTTPS deployment recommended for production traffic and browser trust.

Password & Identity Controls

  • Password hashing and verification logic to protect stored credentials.
  • Reset and recovery workflows for administrative support.
  • Optional email and OTP-based identity verification flows.

Operational Visibility

  • Admin audit log support for sensitive platform operations.
  • Workspace activity events, reminders, notifications, and status changes.
  • Support workflows for investigation and response.

AI Safety Considerations

  • Workspace AI features use only configured keys and relevant workspace context.
  • AI-generated actions should be reviewed before execution in sensitive workflows.
  • Customers control whether AI features are enabled for their workspace.
